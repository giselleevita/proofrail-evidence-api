# ProofRail v1.1 Roadmap

## Infrastructure
- [ ] Horizontal scaling — multiple API instances behind load balancer
- [ ] Dedicated async worker for evidence processing
- [ ] Redis for job queue (replace in-memory)
- [ ] Prometheus + Grafana dashboard

## Features
- [ ] Bulk screening endpoint (`POST /v2/screenings/bulk`)
- [ ] Analyst dashboard (full UI, not just console)
- [ ] Webhook retry with exponential backoff UI
- [ ] Evidence pack versioning
- [ ] Multi-tenant isolation (per-tenant signing keys)

## Security
- [ ] mTLS for internal service communication
- [ ] Audit log export (CSV/JSON)
- [ ] SIEM integration (Splunk/Datadog)
- [ ] SOC 2 Type II evidence collection automation

## DX
- [ ] OpenAPI SDK generation (Python, TypeScript)
- [ ] Postman collection export
- [ ] Sandbox environment with demo data
